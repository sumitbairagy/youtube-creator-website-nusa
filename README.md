# Nusa Creator — Premium YouTube Creator Website

Responsive four-page creator portfolio for an Indonesia-based YouTube creator/client.

## Files
- `index.html` — animated homepage
- `about.html` — creator profile
- `videos.html` — video gallery with category filters
- `contact.html` — contact page and front-end demo form
- `assets/css/style.css` — responsive design and CSS animations
- `assets/js/script.js` — navigation, theme toggle, filters, counters, scroll progress and animation logic

## Technologies
HTML5, CSS3, vanilla JavaScript, AOS, Intersection Observer fallback, GSAP and ScrollTrigger.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages deployment
Upload all files/folders to the repository root. Make sure `index.html` is directly in the root. Then open Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Customize before client handover
Replace the sample brand/name `Nusa Creator` / `Nusa`, YouTube handle `@yourchannel`, email `hello@example.com`, social links (`#`), demo video IDs/titles/views/dates, and sample statistics with the client's real information. Replace Unsplash images with client-approved photos. Current content is written in Bahasa Indonesia.

## Important notes
AOS, GSAP, Google Fonts, Font Awesome and thumbnail images use external CDNs and need internet access. The contact form is front-end only; connect Formspree, EmailJS or a backend before production. All statistics and channel details are demo placeholders, not verified client data.
